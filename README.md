# 📡 ESP32 Wi-Fi Extender

A DIY **2.4GHz Wi-Fi Signal Extender** built using ESP32.

It connects to an existing 2.4GHz Wi-Fi network and rebroadcasts the connection to extend Wi-Fi coverage.

### ✨ Features

* 📶 2.4GHz Wi-Fi only
* 🔄 Wi-Fi repeater/extender
* 🌐 Connects to an existing router
* 📡 Extends wireless coverage
* 🛠️ ESP32 based
* 💻 Arduino IDE compatible

### ⚠️ Note

This project extends **Wi-Fi coverage**, but it does not increase your actual internet speed.

### 🧰 Hardware

* ESP32
* USB cable
* 2.4GHz Wi-Fi router
